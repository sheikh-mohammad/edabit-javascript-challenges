# Medium Difficulty JavaScript Challenges

## Project Overview

This directory contains medium-difficulty JavaScript programming challenges sourced from Edabit-style exercises. Medium challenges typically involve more complex control flow, data shaping, or careful reading of requirements compared to easier levels.

**Project Purpose**: Personal workspace for practicing and deepening JavaScript skills through focused programming exercises.

## Directory Contents

| File | Challenge Title | Topic | Difficulty |
|------|----------------|-------|------------|
| `01-how-much-is-true?.js` | How Much is True? | Array filtering and boolean counting | Medium |
| `02-A-redundant-function.js` | A Redundant Function | Higher-order functions and closures | Medium |

## Building and Running

**Requirements**: Node.js (LTS recommended)

**How to run challenges**:
```bash
node 01-how-much-is-true?.js
node 02-A-redundant-function.js
```

No build process or additional npm packages are required. Each challenge file is a standalone Node.js script.

## File and Code Conventions

- **Problem Statement**: Located at the top of each file in line comments (`//`)
- **Solution Implementation**: Follows the problem statement, uses appropriate JavaScript syntax
- **Testing**: Many files include `console.log()` calls for local verification of solutions
- **Naming**: Files are numbered and use kebab-case derived from challenge titles
- **No Dependencies**: Pure JavaScript, no external libraries or frameworks

## Development Approach

1. **Read the Problem Carefully**: Pay attention to edge cases specified in the Notes section
2. **Implement Solution**: Write code that matches the examples and handles specified edge cases
3. **Test Locally**: Run the file with Node.js to verify output matches expected results
4. **Version Control**: Commit completed challenges to track progress
